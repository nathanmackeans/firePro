How to Convert SVG Logos to PNG/JPG

  1. Using Online Tool (Easiest): Go to convertio.co or cloudconvert.com, upload the SVG file, and convert to PNG or JPG
  2. Using Command Line (Node.js): Install sharp with npm install sharp -D, then use the script in convert-logos.js
  3. Using Browser (Right-click method): Right-click the preview below and save as PNG or JPG
  4. Using Figma (Professional): Upload SVG to Figma, export as PNG/JPG with desired dimensions
  5. Recommended Sizes:
    • Logo (compact): 200x200px for favicons, social media
    • Logo (full): 300x100px for navbar and headers
    • Logo (large): 800x800px for print and marketing materials

Logo - Compact

Recommended Sizes:
• 200x200px (web, social)
• 512x512px (app icon)
• 1024x1024px (print)
💡 Best for: Favicons, social media profiles, small displays

Logo - Full Brand

Recommended Sizes:
• 300x100px (navbar, small headers)
• 600x200px (medium headers)
• 1200x400px (large banners)
💡 Best for: Navbar, headers, email signatures

Logo - Favicon

Recommended Sizes:
• 16x16px (browser tab)
• 32x32px (standard favicon)
• 180x180px (Apple touch icon)
💡 Best for: Browser tabs, bookmarks, app shortcuts
